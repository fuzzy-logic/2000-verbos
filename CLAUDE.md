# Notes for Claude

## Asking the user things

Always ask as **multiple choice, one question at a time**. Never stack several
questions into one message, and never ask open-ended ones where a set of
options would do. Wait for the answer before asking the next.

## Building an audio pack

All 36 packs are built and committed: 34 scene tracks (180 MB), `conj.mp3`
(every one of the 6,399 forms in `data/conjugations.tsv`, 116 min, 29 MB,
with a `verb|slot` seek index) and `tables.mp3`. **Do not rebuild them**
without a reason — a full topic rebuild is ~14,000 clips and about an hour.

```sh
audio/build_all.sh                    # every topic pack, then build.py
CONC=6 audio/build_all.sh             # on a home connection

.venv/bin/python3 audio/make_track.py --topic study-school --concurrency 10
.venv/bin/python3 audio/make_conj_track.py --concurrency 10   # only if conjugations.tsv changed
```

**Topic packs must be rebuilt whenever sentences move between topics**, or a
sentence's audio is stranded in its old topic's pack and its new topic's
walking track is missing it. `build.py` does not catch this; check it with
the pack/deck comparison in the commit for the re-sort.

Safe to re-run: clips are cached by `sha1(voice|rate|text)`. Delete any
`audio/clips/*.part` first if a run was interrupted.

### Concatenate by stream copy, never by re-encode

`-c copy`, which is what both builders now do. Re-encoding on concat decodes
each input first, and the decoder honours the LAME gapless tags, so **every
input loses one frame** — 0.048s at 24 kHz. Over the 12,798 clips and gaps in
conj.mp3 that was 757 seconds of index drift, and the seek index was useless.

The 33 topic packs do not show this because they were built on a machine
whose ffmpeg did not trim. On ffmpeg 6.1 the same script drifts. If a drift
figure comes out large and negative, this is why.

Stream copy also keeps the audio first-generation and joins in seconds. The
Xing header survives it, so browsers still seek accurately.

**`audio/clips/` does not travel.** It is gitignored and container-local
(~146 MB when full). A fresh container re-synthesises every clip.

### Prerequisites that have each cost an hour

- `edge-tts >= 7.3.1`. 7.2.8 returns 403 on everything: Microsoft rotated the
  Sec-MS-GEC token in October 2026 and 7.3.0 fixed it.
  `python3 -m venv .venv && .venv/bin/pip install 'edge-tts>=7.3.1'`
- `ffmpeg` and `ffprobe` must be on PATH. If the environment lacks them, say
  so rather than working around it.
- **In a cloud container**, edge-tts pins its own CA bundle via certifi, so
  the agent proxy's CA has to be appended to it or every request fails TLS
  verification:
  ```sh
  cat /root/.ccr/ca-bundle.crt >> $(.venv/bin/python3 -c "import certifi;print(certifi.where())")
  ```
  `SSL_CERT_FILE` alone does not work. Concurrency 10 is fine through the
  proxy (~180 clips/min, vs ~56/min at 6 locally).

### Verifying a pack

Index drift under 0.5s (the script prints it), every `conjugations.tsv` row
present in the map, and sample offsets:

```sh
ffmpeg -v info -ss START -t DUR -i conj.mp3 -af volumedetect -f null -
```

Speech reads about -20 dB mean, silence about -91. `-v error` suppresses
volumedetect output — it reports at info level. That mistake has been made
twice now.

## Gates

```sh
python3 -I lib/test_conjugate.py
python3 -I lib/test_pron.py
python3 -I lib/check_extra.py
python3 build.py              # fails loudly on broken references
```

And the browser suite, which drives the built site in Chromium:

```sh
cd dist && python3 -m http.server 8137 &
node test/site.mjs --base http://localhost:8137   # before pushing
node test/site.mjs                                # the live deploy
```

136 checks over 14 suites; `--only <suite>` narrows it, `--headed` shows it.
See TEST-PLAN.md for what it covers and what it deliberately does not.

`lib/pron.py` is the only respeller — it feeds the Forms panel, the Verbs tab
and, via `dist/pron.json`, every card. Do not add a JavaScript copy of the
rules; the page reads the generated file. `say()` always marks the stress;
`sentence()` is the one that leaves grammatical and one-syllable words alone.

## Repo conventions

- Netlify deploys from `master`; keep the working branch fast-forwarded into
  it or the site does not update.
- `dist/audio` is tracked in git because Netlify serves it from the repo.
  `.git` is ~470 MB; see the shrink under Still open.
- Never commit `PLAN.local.md` — gitignored, holds personal details.

## Classification

`data/classification.tsv` is the single owner of what a sentence is about,
keyed by sentence key, hand-made, **generated by nothing**. Two axes:

- `scene` — one per sentence, compulsory. What it browses under, and what
  drives the Deck, the audio packs and the walking tracks.
- `tags` — zero or more. A second scene it also touches, or `drill:<family>`
  for the six core-verb families. 832 of 2,766 sentences carry one.

34 scenes in `data/topics/_index.tsv`. The six core-verb families
(being-feeling, doing-handling, yes-no-maybe, seeing-noticing,
thinking-knowing, change-cause) are **tags, not scenes** — their sentences
live in the scene each is about, so "Hace mucho calor" is Weather and carries
`drill:being-feeling`.

`lib/assign_topics.py` and the `topic` columns in the source files are now
dead for classification purposes; do not resurrect them as a second source of
truth.

**Never let a generator own a file's schema.** `check_extra.py` once rewrote
`sentences_extra.tsv` from a hardcoded column list with
`extrasaction='ignore'`, deleting a hand-added topic column and 52 decisions
with it, silently, while every gate passed. `lib/check_classification.py`
round-trips against the file to make that class of bug loud; `build.py` runs
it.

## Still open

- **Surface the tags.** They are recorded and gated but nothing in the app
  reads them: no filter by `drill:hacer`, nothing on the card. Until that
  exists they buy correctness, not a feature.
- **Repo shrink.** `.git` is ~470 MB. `dist/audio` is tracked because Netlify
  serves it from the repo, and the packs have now been rebuilt three times,
  so three generations of pack blobs are dead weight in the history. A rewrite (or moving the
  audio off the repo) would drop them. The user has agreed to this as a
  later piece of work.
- Family trees: small radial SVGs for the ~20 prefix families with 3+ members
  (tener -> mantener/detener/retener/sostener), which share a conjugation.
- More hand-written edges. `data/edges-manual.tsv` has 116 pairs; the graph is
  still thin, and Wander tops up from the same topic because only 179 of 1,919
  verbs have three real links. Every pair added there is a door that means
  something. `build.py` fails loudly if either end is not in the corpus.
